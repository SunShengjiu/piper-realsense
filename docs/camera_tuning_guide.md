# D435i 深度去噪与红外调参

当前目标是减少原始深度中的跳点、误匹配和闪烁，同时保留物体边缘与有效测量。
D435i 通过左右红外图像做双目匹配：应调 **深度 / 红外参数** 中的曝光、增益与投射器功率。
RGB 曝光、RGB 增益和白平衡是另一组参数，不会直接改善原始深度。
反光、透明、遮挡和超出可测距离的区域不一定能靠参数消除空洞，不能承诺完全消除噪点。

## 1. 打开调参界面

```bash
cd /home/robot/shucai1
python3 -m piper_capture.cli \
  --config configs/lerobot_v3_two_d435i_tuned.json \
  camera-ui --output configs/lerobot_v3_two_d435i_tuned.json
```

访问 <http://127.0.0.1:8766>，确认两台相机的序列号后点击“连接 / 应用分辨率”。
若还没有 tuned 配置，改用 `configs/lerobot_v3_two_d435i.json` 作为输入。
更新程序后需在旧服务终端按 Ctrl-C，再重新启动，刷新网页即可加载新界面。

每台相机同时显示 RGB、深度、左红外 IR 1 和右红外 IR 2：

- 深度默认显示**原始深度**，可切换到对齐 RGB 的深度。两种视角的像素位置不同；
  只有对齐深度出现的边缘空洞，可能来自遮挡、视野差异和几何重投影，不宜靠提高增益处理。
- 深度颜色固定映射 0–3 m，黑色表示无测量；超过 3 m 的有效值显示为量程末端颜色，采集值不会因此截断。
- 左右红外使用固定 0–255 灰度，均值、暗部占比（≤5）与饱和占比（≥250）在原始 Y8 图像上统计。
  大片发白、纹理消失提示过曝；大片发黑提示信号不足，但也可能由材料或背景引起。
  全图统计只能辅助判断，目标区域纹理是否清晰更重要；少量亮散斑并不等于整幅图过曝。
- “原始有效 / 对齐有效”是非零像素比例，**不是准确率**。更多有效像素可能包含更多错误深度。
- 左右红外共享深度传感器的曝光和增益，不能分别设置。红外流仅在调参预览时启用。

## 2. 推荐调参顺序

固定相机和目标，使用实际工作距离、照明和材料。先选一块静止、哑光且有纹理的表面作为参考，
再检查实际抓取物体。一次只改一个参数，每次等待画面稳定并比较同一区域。

| 顺序 | 参数 | 操作与判断 |
| --- | --- | --- |
| 1 | 深度预设 `visual_preset` | 先比较 Default 和 High Accuracy。High Accuracy 通常更严格地拒绝不可靠匹配，可能减少飞点但增加空洞；High Density 偏向覆盖率，不能等同于更准确。选好预设后再调曝光等参数，切换预设可能重置其他设置。 |
| 2 | 红外自动曝光 `enable_auto_exposure` | 支持时先观察自动模式，再关闭以固定曝光和增益，便于可重复比较。若该项未显示，说明本次设备查询未获得该控件，可检查重连后是否出现；不要以为 RGB 自动曝光能代替它。 |
| 3 | 红外增益 `gain` | 从设备允许的低值开始；本机两台 D435i 报告最小值为 16。增益会放大噪声，亮度不足时先考虑曝光和投射器功率。 |
| 4 | 红外曝光 `exposure` | 可从 8500 μs（8.5 ms）试起，再比较 4000、8000、12000、16000 μs；这些仅是搜索点。目标过亮就减小，欠曝就增大，以左右红外仍有清晰纹理、深度更稳定为准。 |
| 5 | 红外发射器 `emitter_enabled` | 室内低纹理表面可从 Laser 开启状态试起，观察是否出现可用散斑。外部强红外光、材料反射等会改变效果。 |
| 6 | 投射器功率 `laser_power` | 本机报告 0–360 mW、步长 30 mW。可从 150 mW 起步，比较 90、150、210、270 mW；大面积饱和时降低功率或曝光，不能直接拉满。 |
| 7 | 动态检查 | 静态改善后，再检查实际运动速度下是否拖影、闪烁或帧率下降。腕部运动时通常需要比静态场景更短的曝光。 |

30 fps 的帧周期约为 33.3 ms，但设备允许填写的曝光上限可能远大于此。
不要把范围最大值当作合理工作值；实际曝光可能受固件与帧周期限制，应观察接收帧率和运动图像。
自动曝光 / 自动增益上限可能在开流后只读，某些选项要下次开流才生效；以设备说明和回读为准。

常见现象与下一步：

| 现象 | 优先检查 |
| --- | --- |
| 原始深度平面上随机飞点、左右 IR 很暗 | 保持低增益，逐步增加曝光或投射器功率，检查散斑和材料纹理。 |
| 目标 IR 发白、细节消失，深度破碎 | 降低曝光或功率，改变反光角度，避开直射强光。 |
| 静止时可用，运动时变差 | 缩短曝光；必要时改善照明条件，并重新验证深度。 |
| 物体边缘黑洞，但内部较稳定 | 检查遮挡、对齐及预设的置信度取舍；不要只追求有效比例。 |
| 非常近的物体无深度 | 尝试增加相机与物体距离；最小可测距离与模式有关，曝光无法突破几何限制。 |

## 3. 双相机比较

两台相机需要分别调参。固定曝光和增益后，保持相机位置不动，对比两台投射器都开启、
只开腕部投射器、只开第三人称投射器三种情况，再恢复最佳组合。
如果只有同时投射时某些区域明显变差，再调整投射方向、功率或安装角度。
多台 D435i 不一定产生明显互扰，需要现场对照；`emitter_on_off` 也不是自动的双机协调方案。

调参多开了左右红外流，会增加 USB 带宽。若出现断流，先查 USB 3 直连接口、线材和共享 Hub，
必要时在界面选择设备支持的较低分辨率（如 640×480）进行诊断。
改变分辨率会影响深度质量，最终应在实际采集分辨率下复查。接收 fps 是包含启动后运行时间的平均值。

## 4. 保存与采集验证

点击“保存参数”，再“停止预览 · 释放相机”，使用保存的配置采集：

```bash
.venv-lerobot/bin/python -m piper_capture.cli \
  --config configs/lerobot_v3_two_d435i_tuned.json capture-lerobot --duration 5
```

此采集命令还需要机械臂反馈正常；单独调相机使用 `camera-ui` 即可。
参数保存在各相机的 `sensor_options.depth`，启动采集时重新应用。
自动曝光模式不会把当时的曝光、增益读数保存为手动目标值。
关闭网页不会释放相机，必须点停止或退出服务。

先优化传感器，再评估是否需要后处理。当前调参界面不做空间滤波、时间滤波或补洞；
时间滤波在运动物体上可能拖影，补洞可能生成并非真实测量的值，后续引入时应保留原始深度并分别评估。
可用静止目标同一区域的逐像素时间波动、空洞率、边缘质量和实测距离误差进行比较，
不能用一张看起来更平滑的彩色深度图证明测量更准确。

## 5. 已完成的现场参数调整（2026-09-19）

历史现场试验曾保存并验证：两台红外自动曝光关闭，曝光 8500 μs、增益 16；腕部 Medium Density / 270 mW，第三人称 Default / 360 mW。
腕部原始深度有效比例约 43% → 67%，第三人称 ROI 大于 10 mm 的帧间跳变约 13.4% → 12.0%。这是当前静态场景的结果，仍有剩余噪点，运动和照明变化后需复查。
